⚖️ Pros & Cons

ProsCons
Ships a robust, testable interaction (recenter) instead of an unverified raw-camera + hand-rolled-PnP pipeline.Loses real-world / shared registration for now — the model no longer pins to a fixed physical spot.
Attacks the baseline lag with the correct in-XR lever (framebuffer scale factor + no antialias), not setPixelRatio.Framebuffer downscale softens the rendered model's edges; the ~0.7 value is a starting guess needing on-device tuning.
Drops camera-access, the jsQR import, and the per-frame readPixels loop — smaller permission/compat surface, less work per frame.jsQR stays in package.json unused (dead weight until QR is revived).
QR code kept dormant (like ArSession.ts), so the future site-walk anchoring use case isn't thrown away.Dormant, unimported code can rot / drift from the live path until revisited.
