⚖️ Pros & Cons

ProsCons
Reuses the existing live modal — no two-phase "Compare" screen, no new route/store to maintain. Adds a runtime dependency (jspdf) — a new bundle-size cost, used only in this one feature.
Diff + export follow the currently-selected page on each side, so multi-page sheets work and what-you-see-is-what-you-export. Pixel diff is raster-based: it flags any visual delta (incl. anti-aliasing/resampling noise), not semantic CAD changes. A threshold mitigates but won't eliminate this.
Pure diff/export helpers live in lib/ and are unit-testable; createDiffCanvas normalizes sizes first, fixing the reference's flat-index misalignment bug. Diff recomputes synchronously on every selection change; on very large pages the pixel loop can cause a brief hitch (acceptable — one pass, only when Overlay is active).
Legend swatches use design tokens (status-danger/status-ok); only raw canvas pixels use hardcoded RGB, so JSX token rules stay intact. Modal stays in components/shop-drawings/ though it holds fetch/pdfjs logic — a pre-existing layer deviation this change does not fix (out of scope).
