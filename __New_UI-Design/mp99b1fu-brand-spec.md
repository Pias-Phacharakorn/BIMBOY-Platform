# Brand Specification: LearnThatOpen (Monochrome Tech)

## Core Philosophy
Professional engineering tool. Precision, density, and spatial awareness. Neutral monochrome eliminates visual noise, allowing model data and status indicators to stand out.

## Visual Tokens (OKLch)
- `--bg`: `oklch(12% 0 0)` — Deep charcoal foundation
- `--surface`: `oklch(16% 0 0)` — Panel background
- `--surface-alt`: `oklch(20% 0 0)` — Secondary surface/hover
- `--fg`: `oklch(98% 0 0)` — Primary text
- `--muted`: `oklch(65% 0 0)` — Secondary text/metadata
- `--border`: `oklch(24% 0 0)` — Subtle technical borders
- `--accent`: `oklch(100% 0 0)` — Pure white for active states
- `--status-err`: `oklch(60% 0.15 25)` — Red for clashes/errors
- `--status-warn`: `oklch(85% 0.15 85)` — Amber for warnings
- `--status-ok`: `oklch(75% 0.15 150)` — Green for approval/success

## Typography
- **Display**: Inter/System Sans, tight tracking (-0.02em), medium weight.
- **Body**: Inter/System Sans, 13px/14px base for density.
- **Mono**: JetBrains Mono / IBM Plex Mono for coordinates, dimensions, and IDs.

## Layout Cues
- **Radius**: 4px for most elements, 8px maximum for large cards.
- **Borders**: 1px solid `--border`.
- **Shadows**: None or ultra-subtle 4px blurs for floating toolbars.
- **Density**: Compact. 8px/12px spacing increments.
